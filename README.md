## 📊 Project Overview

This project is an interactive **Amazon Prime Video dashboard developed using Microsoft Power BI**.

The dashboard analyzes Amazon Prime Video content and provides insights into movies and TV shows based on genres, ratings, release years, countries, and content types.

The objective of this project is to transform raw entertainment data into an interactive business intelligence dashboard that makes content trends easier to understand.

---

## 🎯 Project Objectives

* Analyze the distribution of Movies and TV Shows.
* Identify the most common genres.
* Analyze content based on ratings.
* Understand content trends by release year.
* Analyze the number of titles by country.
* Explore the growth of Amazon Prime Video's content library.
* Create interactive visualizations using Power BI.

## 📂 Dataset

The dataset contains information about Amazon Prime Video titles, including:

* Title
* Type
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Listed In / Genre
* Description

The dataset was cleaned and transformed before being used for dashboard development.

## 🔄 Data Preparation

The following data preparation steps were performed using Power Query:

1. Removed duplicate records.
2. Handled missing/null values.
3. Standardized column names.
4. Changed appropriate data types.
5. Cleaned text fields.
6. Extracted useful information from date fields.
7. Prepared the dataset for Power BI analysis.

## 💡 Key Insights

- Movies represent the majority of the content library compared with TV Shows.
- The dashboard contains 9,668 total titles, including 7,814 movies and 1,854 TV shows.
- Drama is one of the largest content categories in the dataset.
- Content is distributed across 30 countries.
- The content growth chart shows significant variation in the number of titles released across different years.
- The age-rating analysis shows that 13+ and 16+ are among the major rating categories.
